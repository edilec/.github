# Edilec community health defaults

This repository contains the account-wide community guidance used by public
repositories maintained under the [`edilec`](https://github.com/edilec)
account.

GitHub may use these files when a public Edilec repository does not provide its
own version. Project-specific documentation always takes precedence because
support boundaries, security assumptions, tests, and release processes differ
between projects.

These defaults do not change the ownership, licence, attribution, or upstream
governance of a fork or third-party project.

| Document | Purpose |
| --- | --- |
| [`CONTRIBUTING.md`](./CONTRIBUTING.md) | Baseline contribution workflow and provenance expectations |
| [`SECURITY.md`](./SECURITY.md) | Private vulnerability-reporting route and disclosure boundary |
| [`SUPPORT.md`](./SUPPORT.md) | Public support scope and information to include |
| [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md) | Conduct standards and private escalation route |
| [`GOVERNANCE.md`](./GOVERNANCE.md) | Ownership, decision-making, and release authority |
| [`MAINTAINERS.md`](./MAINTAINERS.md) | Current accountable maintainer |

These defaults do not create a service-level agreement, security bounty, or
commitment to accept a proposed change. Each repository's maturity label,
licence, documentation, and maintenance status remain authoritative.

Edilec Private Limited maintains this repository. General company information
is available at [edilec.com](https://edilec.com/).
